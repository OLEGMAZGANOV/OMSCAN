# OM Scan

Релизные APK приложения OM Scan для Android.

## Скачать

Актуальная версия находится в [GitHub Releases](https://github.com/OLEGMAZGANOV/OMSCAN/releases/latest).

Устанавливайте релизный APK поверх текущей обычной версии OM Scan, не удаляя приложение. Пакет: `ru.omscan.om2`. Для тестовой версии с другим пакетом этот APK не является обновлением.

Начиная с версии 2.0.37 в настройках приложения есть кнопка «Проверить обновления». Первую версию с этой кнопкой нужно установить вручную.

В этом репозитории размещаются APK-релизы и их описания; исходники и ключи подписи не публикуются.
